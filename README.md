# AzubiQuest – Startpaket für Claude Code

Lern-Plattform für die Berufsschule: **Jede Prüfung ist ein eigenes Spiel.**
Läuft auf PC und Handy, wird unter deiner Domain veröffentlicht.

Erstes Spiel: **„Azubi-Akademie“** – Prüfung „Berufsbildung und Arbeitswelt“ (Buch S. 11–31,
164 Aufgaben + 71 Lernkarten). Weitere Prüfungen kommen als neue Ordner dazu und erscheinen automatisch als neues Spiel.

## Inhalt
| Ordner/Datei | Wofür |
|---|---|
| `CLAUDE.md` | Regeln und Technik – Claude Code liest das automatisch |
| `docs/PLAN.md` | Bauplan in 5 Phasen + fertige Prompts |
| `docs/SPIELMODI.md` | Die Spielmodi in jedem Prüfungs-Spiel (Quiz-Blitz, Gericht, Memory …) |
| `docs/NEUE-PRUEFUNG.md` | Neue Prüfung = neues Spiel (auch direkt aus Buchfotos) |
| `docs/NEUER-SPIELMODUS.md` | Neue Spielmodi für alle Prüfungen |
| `docs/DEPLOYMENT.md` | Online stellen unter eigener Domain |
| `docs/grafiken/` | Mockups, Architektur, Spielablauf, Roadmap, Designsystem |
| `content/pruefungen/` | Ein Ordner pro Prüfung |

## So startest du
1. ZIP entpacken, z. B. nach `C:\Projekte\azubiquest`.
2. Im Ordner Claude Code starten.
3. Ersten Prompt einfügen:

> Lies CLAUDE.md und docs/PLAN.md. Schau dir die Grafiken in docs/grafiken/png an. Setze Phase 1 komplett um und zeig mir am Ende, wie ich die App lokal starte.

4. Danach Phase für Phase weiter (Prompts unten in `docs/PLAN.md`).
